How a cut is made

  1. Transcribelocal faster-whisper, word timestamps
  2. Readtranscript + sampled frames → the brain
  3. Decidebeats, order, motion, pop text + timing
  4. RenderFFmpeg cut · grade · −14 LUFS · burned captions
  5. VerifyA/V drift, black frames, pop-frame screenshots

The brain is a swappable seam

Local rulesSilence-split phrases, number+unit and power-word pops. Offline, free, deterministic. The fallback every other mode degrades to.
Live Claude sessionProduction default on the desktop: a Claude Code session reads transcript + sampled frames and writes the decision file. Covered by a flat subscription.
Anthropic APIUnattended mode for phone-sent jobs: same JSON contract, cents per video, spend-capped. Falls back to local rules on any failure.

The five cuts above were made by the Claude modes; their reasoning is shown verbatim. One JSON contract, three backends — the model is a component, not the system.

Outputs only — raw footage, transcripts, and analytics stay on the machine that made them. Videos are the creator's own published TikTok Shop content. Decision traces are the pipeline's real artifacts, exported by a sanitizing script with a scrub gate.
